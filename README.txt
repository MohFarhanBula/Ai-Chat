Petunjuk Penggunaan:

1. Upload seluruh file script ke hosting atau server Anda.
2. Buat database MySQL dengan nama 'project_chatbot' (atau sesuaikan sesuai kebutuhan).
3. Import Database
4. Masukkan API key Hugging Face Anda di tabel 'settings' dengan key 'api_key'.
5. Sesuaikan koneksi database di file (functions/connect.php atau sesuai nama file Anda).
6. Pastikan PHP sudah versi 7+ dan extension cURL aktif di server Anda.
7. Buka halaman chatbot melalui browser, mulai chat dan nikmati fitur AI chatbot.

----------------------------------------------------------------------------------------------------------------------------------------------

Catatan Penting:

- Simpan API key Anda dengan aman dan jangan bagikan secara publik.
- Penggunaan API Hugging Face dikenakan biaya sesuai kuota pemakaian.
